# Pokémon Binder

A live National Pokédex binder, numbered set checklists, and tracked estimated collection value.

- **[National Pokédex binder](https://hfrog713.github.io/pokemon-binder/)**
- **[Set-by-set checklists](https://hfrog713.github.io/pokemon-binder/sets.html)**
- **[Collection value history](https://hfrog713.github.io/pokemon-binder/values.html)**
- **[Top 10 ungraded and hypothetical PSA 10 cards](https://hfrog713.github.io/pokemon-binder/values.html#top-cards)**
- **[Collection intake + valuation SOP](COLLECTION-WORKFLOW.md)** — the canonical repeatable process across new-pull and hidden-card threads.

Collection data is sourced from the owner's master Google spreadsheet through a read-only public Sheets mirror. Changes are applied when a new collection batch is processed; the site does not autonomously identify cards, update static set-checklist ownership, or reprice without a new session.
